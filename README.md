# PhysTacGen

Official repository for **PhysTacGen: Physics-Aware Visual-Tactile Sensor Image Generation**.

**Accepted at NeurIPS 2026.**

**Guo Tang, Yongtao Wang**  
Wangxuan Institute of Computer Technology, Peking University

## Overview

PhysTacGen is a visual-to-optical-tactile image generation framework that combines GTPO-generated material descriptions, DINOv2-based pair curation, relative-depth priors, and an SDXL ControlNet conditioned on RGB, depth, and text.
